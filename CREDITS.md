## Noctalia plugins

Enabled in the shipped config:

- `miixz/audio-sticker` — audio-reactive desktop stickers
- `levi/warp` — warp/workspace indicator
- `noctalia/bongocat` — bongocat widget
- `kenn/keybind-cheatsheet` — searchable keybind overlay
- `noctalia/wallhaven` — Wallhaven browser
- `dotnetrob/cat` — animated cat widget
- `viksit-garg/wayvibes` — Wayvibes control widget
- `oldirtty/color_picker` — screen color picker

Sources: `noctalia-dev/official-plugins` and `noctalia-dev/community-plugins`.
Each plugin keeps its own license (see its `plugin.toml` / `LICENSE`).

## Themes

- **Vesktop / Discord** — *Noctalia Midnight* and *Noctalia Material*, forks of
  [Midnight Discord](https://github.com/refact0r/midnight-discord) by refact0r (MIT).
- **Noctalia templates** — `discord`, `zen-browser`, `spicetify-noctalia`
  from the Noctalia community template store.
- **Floorp** — animated **Spirited Away** theme by **Max** on
  [Mozilla Add-ons](https://addons.mozilla.org/firefox/addon/spirited-away-animated/).
  `userChrome.css` / `userContent.css` are the stock Floorp templates.
- **Zed** — Noctalia-generated theme file.
- **GTK / KDE / btop / cava / kitty** — generated by Noctalia's template processor
  from the active wallpaper palette.

## Removal requests

If you are an artist or maintainer and want an asset removed, please open an
issue at https://github.com/IgnazBhatta/mintalia/issues and it will be removed
promptly.
